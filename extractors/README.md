# 平台媒体提取器（实验阶段）

独立实现的抖音、TikTok 页面提取模块，尚不是可安装音源插件。没有复制外部提取器代码，也没有添加登录、Cookie 导入、签名生成、挑战执行或付费解锁逻辑。

**目前不能宣称已经支持这两个平台的搜索或实际播放。** 不加入 `index.json`，不更改已发布插件。

## 当前实现

- `douyin.mjs`：解析页面 `RENDER_DATA` 中与请求 ID 匹配的视频记录。
- `tiktok.mjs`：解析页面 JSON 中的视频详情或旧版条目状态。
- `search-response.mjs` / `guest-search-parser.cjs`：共享同一原始解析器，校验观测到的官方响应来源、查询、实际游标，按服务器分页、跨页去重、排除明确受限项；未知权限仍标记 `unverified`，不导出临时媒体地址。解析器与 `tools/runtime/guest_search_capture.js` 逐字节镜像到宿主可选访客通道，不复制外部算法。
- `page-client.mjs`：分享文本/短链接识别、同平台 HTTPS 白名单、最多四次重定向、15 秒请求超时、2 MiB 响应上限、取消与结构化错误。
- `access-policy.mjs`：排除明确的 VIP、收费、订阅、试听、私密内容；权限或完整性证据不足也拒绝，不将字段缺失解释为免费。
- `media.mjs`：返回受限 CDN 范围内的原始视频流及请求头；不使用音乐素材片段，不改写水印路径。

提取结果是视频自身音轨的候选来源，可能包含视频，需要播放后端单独验证。`fullSong: false` 表示**不承诺是完整歌曲**，并不表示所有视频都被判断为试听；完整短视频与完整歌曲不是同一概念。

权限字段别名当前是保守输入契约，单元测试中的明确免费/非试听标记是合成测试数据，不是声称平台真实页面总会提供这些字段。必须补充真实字段映射与证据才能发布；禁止为了让测试或链接通过而人工给未知内容填“免费/非试听”。

## 接口

模块以 ES module 提供，当前在 Node 测试中运行。不是宿主已支持的单文件 CommonJS 插件，不可直接粘贴到 App 安装。

- `parseDouyinPage(html, {id, url})` / `parseTikTokPage(html, {id, url})`：纯解析，不发送请求。
- `createDouyinExtractor({request})` / `createTikTokExtractor({request})`：返回 `extract(shareText, {signal?})`。
- `request(url, options)`：调用方注入的 HTTP 传输，返回 `{status, headers, data, url?}`；data 为 HTML 文本。
- `parseSearchResponse(platform, payload, {requestUrl, query, cursor?})`：纯解析官方搜索响应，返回 `{data, isEnd, nextCursor, excludedCount}`。
- `SearchResultCollector(platform, query).append(payload, requestUrl)`：短期会话内按实际游标收集并跨页去重；拒绝重放、倒退游标和过量结果。它不生成签名、不发送搜索请求，不意味着 App 已接线。

传输必须：

1. 遵守 `redirect: 'manual'`，不自动跟随重定向、不持久化或重放 Cookie。
2. 在读取响应期间强制执行 `maxBytes`，不是下载完再截断；响应按 UTF-8 解码。
3. 使用 `signal`、超时和宿主的 DNS/地址安全检查；域名白名单不等于 DNS rebinding 防护。
4. 媒体实际播放和每次重定向仍通过宿主出网检查，不能把返回 URL 直接交给不受控的网络客户端。

当前 App 的 HTTP 桥接有自己的重定向行为，不能假设已经满足这个传输契约。沙箱接线、协议与平台适配另行实现。本模块没有默认网络客户端，也不启动进程或后台服务。

异常带稳定 `code`，不带页面正文、Cookie、签名媒体 URL 或原始网络错误。输出中的媒体地址只供临时播放，不写入业务库或日志。

## 实测状态

本次匿名访问探测仅保留本地临时响应，不提交真实作者、视频、签名 URL 或匿名会话数据：

| 项目 | 观察结果 | 当前结论 |
|---|---|---|
| TikTok 一个公开视频页 | 返回结构化视频数据，但缺少足够的免费/非试听证据 | `access_unverified`，拒绝自动播放 |
| TikTok 官方访客搜索 | 原型五页 60 主视频；可选 App 桥接已通过真实插件 JS/RPC/原生通道五页 50 条无重复结果，任务释放验证通过 | 普通关键词仍有拒绝/空体，播放复核权限不足；未安装启用，不把一次搜索成功扩大为完整交付 |
| 抖音官方访客搜索 | 正常窗口加载后出现验证提示，没有真实搜索响应 | 需要用户参与的正常验证路径；不自动解验证码、不绕过访问控制 |

离线测试覆盖两个解析器、权限过滤、错误、重定向、大小、超时和取消。通过离线测试不等于实时平台可用，更不等于五端播放成功。

## 下一步与完成标准

1. 使用有权访问的公开视频样本核实抖音页面结构和两平台权限/试听字段；不能依赖猜测或标题关键词判断免费。
2. 分别调查并实现歌曲名、歌手、关键词的真实平台内搜索、分页与搜索结果点播，不以链接提取替代搜索。
3. 将过滤用于搜索候选和播放前复核；未知内容不自动播放，空结果与接口失败区分。
4. 将已验证逻辑接入宿主支持的协议与沙箱；验证媒体 HTTP、Range、seek、后台音频、过期恢复和资源预算。
5. 只有完成搜索、链接导入和逐端真实播放后，才能发布对应插件并加入订阅。
