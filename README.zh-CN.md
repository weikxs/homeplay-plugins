# HomePlay Plugins

[English](README.md) | **简体中文**

免费的插件，用来**在家播放你自己的音乐**：NAS 上的音乐服务器、WebDAV 文件夹里的歌，以及你自己注册的开放
音乐库。一个订阅链接搞定，除了你正在用的 App，什么都不用另外安装。

- **免费**：不用在我们这里注册，没有广告，没有付费版。
- **源代码公开**：每个插件都是一个可以直接阅读的 JavaScript 文件，安装前就能看清它做什么。
- **简洁**：订阅链接加一次，App 会列出所有插件，你想更新时一键更新。
- **轻便**：不需要构建，不需要下载依赖；每个插件只有几 KB。
- **私密**：服务器地址、用户名和密码只保存在你设备上的 App 里，只发给你填写的那台服务器，本仓库永远不会
  经手。

> **状态：早期。** 仓库正在搭建，下面的插件还在计划中，尚未发布。见 [CHANGELOG.md](CHANGELOG.md)。

## 插件

| 插件 | 能播放什么 | 需要你填写 | 状态 |
|---|---|---|---|
| Subsonic | Navidrome、Airsonic 等兼容 Subsonic 的服务器 | 服务器地址、用户名、密码 | 计划中 |
| Jellyfin | Jellyfin 服务器上的音乐库 | 服务器地址、用户名、密码 | 计划中 |
| Emby | Emby 服务器上的音乐库 | 服务器地址、用户名、密码 | 计划中 |
| WebDAV | WebDAV 文件夹里的音频文件（NAS、支持 WebDAV 的网盘） | 文件夹地址、用户名、密码 | 计划中 |
| Plex | Plex 服务器上的音乐库 | 服务器地址、Plex 令牌 | 计划中 |
| Jamendo | 免费的开放授权音乐 | 你自己申请的 Jamendo client id | 计划中 |
| Podcast Index | 播客 | 你自己申请的 Podcast Index API key 和 secret | 计划中 |

插件只连接你自己运行的服务，或对所有人开放接口的服务。本仓库不包含、也不会接受任何绕过平台访问规则的
插件。

## 支持的 App

插件使用 [TimbreBox](https://github.com/weikxs/timbrebox) 的插件格式。TimbreBox 是一个免费的音乐播放器，
支持 Windows、macOS、Linux、iOS 和 Android。其他能运行这种格式插件的 App 也可以使用。

## 安装

首批插件发布后：

1. 打开 App 的插件设置。
2. 添加订阅链接：

   ```text
   https://raw.githubusercontent.com/weikxs/homeplay-plugins/main/index.json
   ```

   也可以只添加某一个插件文件的链接。
3. 填写插件的设置（插件旁边的调节按钮）：服务器地址、用户名和密码。

**家庭网络地址：** 服务器在家里的局域网上（比如 `192.168.0.10`）时，需要 App 允许插件访问你在它的设置里
填写的地址。TimbreBox 目前还不允许，已在计划中。
