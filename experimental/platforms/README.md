# 开发中的平台插件

这些文件尚未发布、不在订阅中，也没有被自动安装。**四个平台尚未全部完成。**

## 使用前提

- 手动导入后，文件本身会加载，但先检查宿主能力，缺能力时不伪造空结果。
- 除 `bilibili.js` 外都需要宿主提供 `env.media.source` 固定媒体桥接；没有该桥接的宿主返回 `extractor_unavailable`，而不是普通“无结果”。
- YouTube 等适配器还要求宿主已配置并校验本地解析组件；缺少配置时错误同样来自宿主。
- 文件声明 `experimental: true` 与 `requiredCapabilities`，版本为预发行号；两者都不得进入 `plugins/` 正式目录或 `index.json`，由 `make check` 强制。
- 当前均为本机 Debug 测试路径，不代表发行包、商店或五端可用；不自动登录、不读浏览器 Cookie、不自动解验证码。

| 文件 | 真实关键词搜索 | 播放状态 |
|---|---|---|
| `bilibili.js` | 官方匿名 HTTP 搜索、第二页已在 macOS 沙箱应用验证 | 独立音频、暂停/恢复、seek、保存引用重载、长链接导入通过静音原生验收 |
| `youtube.js` | 三组真实关键词、第二页已在 macOS 沙箱应用验证 | 实际音频 HTTP 206，原生播放、暂停/恢复、seek、稳定引用重载、长链接导入通过静音验收；已在本机测试版启用 |

| `tiktok.js` | 可选 macOS 测试桥接已通过真实插件 JS/宿主 RPC 五页、50 条去重；其他关键词仍观察到拒绝/空体 | 播放前真实复核返回权限未核实，未通过音频验收；仅按用户要求启用本机实验，不列正式可用 |

## B 站路径

B 站插件为自包含 CommonJS，仅用已有 HTTP 桥接，**不依赖外部工具、桌面媒体 RPC、登录、扫码或用户 Cookie**。
可手动导入开发文件 `experimental/platforms/bilibili.js` 进行测试；不要把它作为正式订阅承诺。

- 按需从官方接口建立服务端生成的匿名临时会话，共享并发初始化，五分钟过期；只存在 JS 引擎内存中，不写文件、设置、收藏或日志。
- 搜索只取标题、作者、时长、图片及稳定视频/分 P 标识，不批量预解析媒体；宿主将结果显示为“视频音轨”，不冒充正式发行歌曲。
- 每次播放重新读取官方内容权限和对应分 P，再请求音频；收藏中伪造的权限、CID 和媒体 URL 不受信任。
- 要求明确的公开状态、付费/专享/试听/后台限制字段均为明确否定；未知字段值或缺少关键证据时拒绝。
- 播放响应未提供统一试听字段时，使用上述明确免费权限与对应分 P 完整时长双重核对；不人为添加免费或非试听标签。
- 仅选官方返回的 HTTPS AAC 音频及已知 CDN，码率上限 192 kbps；保留官方备选地址，不改写签名，不转码，不使用音乐素材试听。
- 长链接已通过真实应用验证。分 P 路径及短链接已有协议/越域测试，但尚缺真实播放验收，不能把这些项目标为完成。
- 沙箱、逐跳出网、Range 和媒体代理仍由宿主负责。宿主现在暴露 axios 的最终响应 URL，并在跨源重定向时剥离认证、Cookie 和自定义敏感头。
- 切换查询取消旧调用时，宿主会实际关闭旧 HTTP 连接，并拒绝旧调用的后续请求，避免串页或阻塞下一次搜索。

三组真实查询（歌曲名、音乐家、组合关键词）分别返回 8、9、10 条筛选后候选，均通过原生播放、暂停/恢复、seek、保存引用重载和长链接导入。
自动验收使用真实平台数据和原生音频后端，保持静音，不代表人工听音、后台系统切换或五端验证已经完成。

## 其他三源

这三个适配器使用 `env.media.source(platform)`。TikTok/抖音的系统 WebKit 搜索通道需显式 Debug define `TIMBREBOX_GUEST_SEARCH_TEST=true`，默认关闭；不提供任意网页/脚本/凭据 API。用独立 nonPersistent 访客数据和官方前端自身请求，真实拒绝保留为错误，不转为空成功；限时关闭所有自有视图，不常驻浏览器。上限 50 条稳定元数据快照供 1–5 页使用，不预解析媒体。该通道尚未满足全部准入和播放验收。

播放解析仍需显式配置、校验桌面解析组件。YouTube 本机测试版使用经过审查、逐文件校验的目录式组件及固定 JS 运行时；在应用沙箱内按需启动，退出时清理工作进程，不读取用户 Cookie、不常驻、不自动更新。该本地测试组件约增加 220 MB，不进入默认发行包。插件不能选择可执行文件、shell、环境或开关；旧运行时没有该桥接，不能安装这些适配器。

普通公开 YouTube 内容按真实提取器的公开状态、非直播、非年龄限制、完整时长及非 DRM 元数据形成访问证据；不补造付费/试听布尔值，已知付费/试听标记优先否决。通过权限检查后，宿主对音频候选实际读取最多 1 KB，拒绝 403、HTML 和不可读格式，必要时退到同一视频真实可读的低码率音轨。代理用有界 Range 窗口接入原生播放器。三组真实音乐查询均通过音频与操作验收。

有资源上限的渐进 MP4/WebM 复合流仅作为后备，播放器仍关闭视频解码；此次真实验收选中的是独立音频，不把复合流单独验收也算通过。YouTube 仍需短链、真实付费/试听反例、过期、后台和其他系统验证，不能据此宣布四源全部发布。

抖音和 TikTok 仍需真实搜索实现。不能把 HTTP 200 的空体、拒绝信息、推荐结果、链接解析或离线测试当作歌曲搜索成功。未验证的权限继续拒绝自动播放。

## 验证与发布

`make check` 运行离线协议、过滤及失败分支测试；这些固定测试响应不是平台可用性证据。
真实设备验收入口在 TimbreBox 的 `integration_test/live_plugin_audio_test.dart`，工具沙箱单独检查位于 `integration_test/media_tool_sandbox_test.dart`，均须显式启用。

B 站尚需真实短链接、地址过期、系统后台与逐端验证，以及更多真实付费/试听反例。四源分别完成要求后才能移入发布目录和加入 `index.json`。禁用或卸载开发插件即可回退，现有订阅与 Subsonic 不受影响。
