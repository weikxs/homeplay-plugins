# Subsonic

[English](README.md) | **简体中文**

搜索并播放你自己的 Subsonic 兼容服务器上的音乐：Navidrome、Airsonic-Advanced、Gonic 等。

## 设置

| 设置项 | 填写什么 |
|---|---|
| Server address（服务器地址） | 你打开这台服务器用的地址，比如 `http://192.168.0.10:4533`；装在子路径下时填 `https://music.example/navidrome` |
| User name（用户名） | 你在服务器上的用户名 |
| Password（密码） | 你在服务器上的密码 |

服务器在家里的局域网上时，请填它的 **IP 地址**（或 `.local` 名字），不要填域名：App 只会为你亲手填写的地址
放行局域网访问。TimbreBox 需要支持插件访问家庭网络的版本。

**建议：** 在服务器上给播放器单独建一个没有管理员权限的账号。

## 功能

- **搜索**：按歌名、歌手或专辑搜索歌曲，每页 30 首。
- **播放**：播放原始文件。
- **歌词**：服务器提供时显示带时间轴的歌词（OpenSubsonic 歌词扩展），否则显示纯文本歌词。

## 隐私

每个请求都按 Subsonic API 规定的方式签名：用户名、每次新生成的随机盐值，以及 `md5(密码 + 盐值)`。密码本身
从不发送、不写日志、不出现在错误信息里。播放地址里带着这个一次性签名，只发往你的服务器。不显示封面：封面
地址会带着签名，进入 App 的曲库记录。

## 测试过的服务器

Navidrome 0.64.2（搜索、播放、带时间轴和纯文本歌词、密码错误、服务器未开启）。
